# Vórtex Split AV

Vórtex Split AV, de Vortex Company: corta y une video o audio por rangos de tiempo exactos con FFmpeg WebAssembly corriendo dentro de tu navegador. Tus archivos nunca salen de tu equipo. Gratis, sin anuncios y 100% local.

## Stack

- Next.js 16 + React 19 + Tailwind 4 + TypeScript
- 100% local en el navegador, sin backend y sin variables de entorno

## Desarrollo

```bash
bun install
bun run dev
```

## Producción

```bash
bun run build
```
